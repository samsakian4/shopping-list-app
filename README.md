# لیست خرید ما

لیست خرید مشترک بین تو و همسرت — زنده (real-time)، با پیشنهاد خودکار موقع تایپ، برآورد قیمت، و تاریخچه‌ی خرید.

## وضعیت فعلی
✅ بک‌اند (Supabase) کامل ساخته و متصل شده — پروژه‌ی `shopping-list-app` توی حساب Supabase که وصل کردی.
✅ ۵ جدول با Row Level Security فعال (هیچ خانواده‌ای دیتای خانواده‌ی دیگه رو نمی‌بینه).
✅ Realtime روشنه — هر تغییری که تو یا همسرت بدید، آنی روی گوشی اون یکی می‌افته.
✅ فایل‌های اپ (index.html / style.css / app.js / products-data.js) آماده و به Supabase وصل‌اند.

## محدودیت‌هایی که از اول باید بدونی
- **پیشنهاد تایپ (autocomplete)** به گوگل وصل نیست — چون گوگل چنین API عمومی‌ای نداره. یه دیتابیس محلی از ~۸۵ کالای رایج ایرانی با برند/سایز داخل `products-data.js` گذاشتم که آفلاین هم کار می‌کنه (مهم چون قبلاً با دسترسی API از ایران مشکل داشتی). هر موردی که توی کاتالوگ نباشه رو می‌تونی به‌عنوان «مورد سفارشی» اضافه کنی — خودش به کاتالوگ مشترک خانواده‌تون اضافه می‌شه و دفعه‌ی بعد هم پیشنهاد داده می‌شه.
- **قیمت‌ها تقریبی‌اند** (بر پایه‌ی بازار تیر ۱۴۰۵) و امیران فروشگاه آنلاین با لیست قیمت عمومی نداره که بشه زنده ازش کشید. راه‌حل واقعی‌تر همینه که پیاده کردم: هر بار که تیک می‌زنی، اگه قیمت واقعی رو وارد کنی، دفعه‌ی بعد که همون کالا رو اضافه کنی برآورد از تاریخچه‌ی خودِ خانواده‌تون محاسبه می‌شه — یعنی بعد از چند هفته استفاده، برآوردها دقیقاً مطابق قیمت‌های امیران خودتون می‌شن، نه یه میانگین کشوری.

## یه نکته درباره‌ی تایید ایمیل
اگه بعد از ثبت‌نام پیام «ایمیلت رو چک کن» دیدی، یعنی تایید ایمیل توی تنظیمات Supabase فعاله. برای رد شدن سریع (چون فقط دو نفرین): Supabase Dashboard → Authentication → Providers → Email → گزینه‌ی «Confirm email» رو خاموش کن.

## چطور همسرت وصل بشه
۱. تو ثبت‌نام کن → «ساخت خانواده جدید» → یه کد ۶ رقمی می‌گیری.
۲. کد رو براش بفرست (پیامک/تلگرام).
۳. اون ثبت‌نام می‌کنه → «پیوستن با کد» → کد رو می‌زنه.
از اون به بعد لیست، تاریخچه، و برآورد قیمت بین هر دوتون زنده مشترکه.

## اضافه‌کردن کالا به کاتالوگ پایه
فایل `products-data.js` رو باز کن، به آرایه‌ی `PRODUCTS_SEED` یه خط جدید اضافه کن:
```js
{ name: "...", brand: "...", size: "...", unit: "...", category: "...", price: 00000 },
```

## مسیر تلفیق با «مالی خانواده»
این اپ *عمداً* توی یه پروژه‌ی Supabase کاملاً جدا از Mali-family ساخته شده (طبق خواسته‌ات، چون اون پروژه قراره جدا ادامه پیدا کنه). ساختار جدول‌ها (households / profiles با invite-code) رو طوری طراحی کردم که همون الگو رو عیناً می‌شه توی هر پروژه‌ی دیگه‌ای هم پیاده کرد. اگه یه روز خواستی واقعاً یکی‌شون کنی، ساده‌ترین راه اینه: دیتای این پروژه (households/profiles/shopping_items) رو export و به پروژه‌ی مقصد import کنیم — چون اسکیما از قبل هم‌شکله، این کار چند خط SQL بیشتر نیست.

## فایل SQL
`supabase-schema.sql` رو نگه دار — همون چیزیه که الان روی پروژه‌ات اجرا شده. اگه یه روز خواستی همین اپ رو روی یه پروژه‌ی Supabase دیگه هم بالا بیاری، کافیه همین فایل رو توی SQL Editor پروژه‌ی جدید اجرا کنی.
